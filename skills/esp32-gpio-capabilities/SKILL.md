# GPIO 能力与冲突

板上连接来自根目录网表手册；芯片能力以 Espressif ESP32-D0WD-V3 数据手册为准。
其他 Skill 若提及 GPIO，只用于说明本领域接法；发生冲突时以本表为准。

## 完整板级映射

| GPIO | 板上连接/引出 | 可用性与约束 |
|:---:|---|---|
| 0 | BOOT(K1)，J5_15/16 | 受限；复位时低电平进入下载模式 |
| 1 | U0TXD→CP2102N（经 R14） | UART0/REPL 占用 |
| 2 | J7_1 | 启动 Strapping；复位时需满足启动电平 |
| 3 | U0RXD←CP2102N | UART0/REPL 占用 |
| 4 | J8_1 | 通用；**不是 ESP32 Strapping 引脚** |
| 5 | J4_1/2 | Strapping；外设不得在复位时强拉错误电平 |
| 6~11 | ZB25VQ32 专用 SPI Flash | GPIO6~11 禁用，绝不可作用户 GPIO |
| 12 | J4_3/4 | MTDI Strapping；复位时拉高可能选成 1.8V Flash 而无法启动 |
| 13 | J9_1 | 通用 |
| 14 | J4_5/6 | 通用 |
| 15 | J10_1 | MTDO Strapping；外拉会影响启动日志配置 |
| 16 | MPU6050 SDA，J5_3/4 | 板载 R7 10kΩ 上拉 |
| 17 | MPU6050 SCL，J5_1/2 | 板载 R8 10kΩ 上拉 |
| 18 | J4_7/8 | 通用 |
| 19 | J4_9/10 | 通用 |
| 21 | J4_11/12 | 通用 |
| 22 | J4_13/14 | 通用 |
| 23 | J4_15/16 | 通用 |
| 25 | 蜂鸣器经 J11，J5_5/6 | DAC1；他用前拔 J11 |
| 26 | MX620B IN1 | DAC2；数字/PWM 会驱动电机接口 |
| 27 | MX620B IN2 | ADC2/T7；数字/PWM 会驱动电机接口 |
| 32 | LED2 绿，J5_13/14 | ADC1/T9；低电平点亮 LED |
| 33 | LED3 红，J5_11/12 | ADC1/T8；低电平点亮 LED |
| 34 | KEY2(K3)，J5_9/10 | 仅输入，无内部上下拉；板载 R9 1kΩ 上拉 |
| 35 | KEY1(K4)，J5_7/8 | 仅输入，无内部上下拉；板载 R12 1kΩ 上拉 |
| 36~39 | 未见引出 | 芯片有输入/RTC/ADC 能力，但本板不可方便接入 |

## 芯片能力分组

- 仅输入且无内部上/下拉：GPIO34~39；本板直接引出的只有 34/35。
- Strapping：GPIO0、2、5、12、15。GPIO4 不在此列。
- ADC1：32(CH4)、33(CH5)、34(CH6)、35(CH7)，以及未引出的 36(CH0)、39(CH3)。
- ADC2：4(CH0)、15(CH3)、13(CH4)、12(CH5)、14(CH6)、27(CH7)。
- DAC：25(DAC1)、26(DAC2)。
- 触摸：4(T0)、0(T1)、2(T2)、15(T3)、13(T4)、12(T5)、14(T6)、
  27(T7)、33(T8)、32(T9)。
- RTC GPIO：0、2、4、12~15、25~27、32~39；包括 GPIO34/35。
- 外部 GPIO 中断：所有数字 GPIO；输入专用脚也能中断。
- LEDC/RMT 输出：可路由到具备输出能力的 GPIO，不包括 34~39。

## 电气约束

- 逻辑电源为 3.3V；GPIO 不耐 5V。
- 官方极限与保证条件不可当作设计工作电流。按保守设计将持续负载控制在
  约 12mA/脚，并用晶体管、MOSFET 或驱动器带电机、喇叭、继电器等负载。
- 数据手册给出的典型驱动档位最高约 40mA、灌电流保证值与电源域总能力均受条件
  限制；不要用“40mA/脚”计算整板负载。
- 典型保证条件：12mA 负载下 VOH≥2.64V、VOL≤0.495/0.66V（以所查数据手册
  版本和驱动档位为准）。
- 板载 LED 已有限流，板载蜂鸣器和电机已有驱动电路。外接电路必须共地。

## 冲突矩阵

| 使用资源 | 同时避免 | 原因/处理 |
|---|---|---|
| Wi-Fi | ADC2 的 4/12~15/27 | ADC2 与无线驱动互斥；改用 ADC1 |
| UART0 REPL | GPIO1/3 普通 IO | CP2102N 与 REPL 已占用 |
| GPIO25 非蜂鸣器用途 | J11 保持连接 | 先拔跳线隔离 Q3 |
| GPIO26/27 非电机用途 | 电机仍接 J6 | 会驱动 H 桥 |
| GPIO32/33 模拟/触摸 | 同时驱动 LED | 板载 LED 形成负载 |
| GPIO34/35 | 输出或内部 `PULL_UP` | 硬件只输入，依靠板载上拉 |
| SPI/总线共享 | 不同 mode/速率设备无管理地共用 | 独立 CS，并在访问前重配总线 |

## 启动与中断规则

不要笼统写“GPIO12 必须低、GPIO15 必须高”；实际启动值由芯片内部默认拉阻与板外
电路共同决定。关键是外设在复位阶段不得覆盖正确 Strapping。GPIO0 低会选择下载
模式；GPIO12 高可能把 VDD_SDIO 选为 1.8V；GPIO15 影响 ROM 日志。

ISR 中只设置标志或写预分配缓冲，不打印、不创建对象。按键中断还需在主循环消抖。
总线、模拟输入、睡眠唤醒的具体用法分别加载对应 Skill。
